# Investigation

Use for explanations, architecture discovery, and questions about observed behavior.

1. Run Matt Preflight in read-only mode and state the exact question being answered.
2. Find entry points, owners, callers, data flow, boundaries, and relevant tests.
3. Trace at least one concrete path through the system; distinguish executed behavior from merely reachable-looking code.
4. Read history or ADRs only when the question is about intent, ownership, or why a surprising design exists.
5. Challenge the leading explanation with contradictory evidence.
6. Answer with direct evidence, clearly labeled inference, and remaining uncertainty.
7. Do not edit files unless the user changes the request.
